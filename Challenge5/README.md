# Swift/iOS Learning

Architecture-neutral workspace for learning Swift/iOS fundamentals with Hermes, Codex, and Obsidian.

## Intent

Learn Swift/iOS from fundamentals toward advanced topics through hands-on practice, manual-first coding, and small artifacts that can grow into showcase projects.

## Folders

- `Exercises/` — small Swift syntax/concept exercises.
- `Apps/` — SwiftUI/Xcode app projects and prototypes.
- `Playgrounds/` — Swift playground experiments.
- `Resources/` — references, assets, screenshots, or supporting files.

## Workflow Rules

- No forced MVVM or architecture at the start.
- Fian chooses the topic; Hermes helps scope it.
- Core learning code is manual-first.
- Codex helps with scaffold, TODOs, debug, review, refactor, and boilerplate.
- Verify before calling an artifact working.

## Artifact Levels

1. Snippet / exercise
2. Mini prototype
3. Small working app
4. Showcase artifact
