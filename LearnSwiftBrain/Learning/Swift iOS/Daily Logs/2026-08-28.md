## Day 1 - SwiftUI State Behavior

Hari ini gua belajar behavior kecil di SwiftUI:

Behavior:
- Tap button
- Status text berubah dari `Ready` ke `Practice Started`

Yang gua pahami:
- `@State` menyimpan data milik `View`.
- `Text(practiceStatus)` membaca nilai dari state.
- `Button` punya action closure yang jalan saat button ditekan.
- Di dalam action, state bisa diubah:
  - `practiceStatus = "Practice Started"`
- Saat `@State` berubah, SwiftUI menghitung ulang `body`.
- Karena `body` membaca state baru, UI ikut berubah.

Mental model:
`Button ditekan → state berubah → body dihitung ulang → Text tampil dengan nilai baru`
